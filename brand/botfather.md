# Оформление бота в @BotFather

Картинки лежат рядом: `avatar.png` (аватарка бота, 640×640) и `cover.png` (обложка Mini App, 640×360).
Пересобрать их: `node scripts/make-brand.mjs`.

## Имя — /setname (до 64 символов)

```
Дымный дворик
```

## Коротко о боте — /setabouttext (до 120 символов)
Видно в профиле бота и при пересылке.

```
Мультяшная кальянная в Telegram: собирай миксы, забивай чашу, держи жар и радуй гостей. 18+
```

## Описание — /setdescription (до 512 символов)
Видно в пустом чате с ботом до первого нажатия «Запустить».

```
Добро пожаловать в «Дымный дворик»!

Ты — хозяин маленькой кальянной во дворе. Заходят студенты, байкеры, блогерши, депутаты, вайбкодер с «Тропиками 8» и даже таинственный незнакомец — каждый со своим заказом.

• Собирай миксы из 30+ вкусов — от мяты до плова
• Забивай чашу и держи жар
• Прокачивай кальянную: от табуреток до неона
• Придумывай фирменные миксы и кидай друзьям

Жми «Играть» внизу.
Игра для взрослых 18+.
```

## Описание Mini App — /myapps → приложение → Edit Description

```
Мультяшная кальянная: собирай миксы, забивай чашу, держи жар и угадывай заказы смешных гостей. 18+
```

## Кнопка меню — /mybots → бот → Bot Settings → Menu Button
Адрес: `https://t1granblack.github.io/dymny-dvorik/`
Текст кнопки:

```
Играть
```

## Команды — /setcommands
Пока не ставить: бот без сервера на команды не отвечает. Добавим вместе с ботом на Cloudflare:

```
play - Открыть кальянную
help - Как играть
```
